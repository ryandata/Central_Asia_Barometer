# Central_Asia_Barometer

Illustrating analysis on Central Asia Barometer data. Originally developed for presentation at [American University of Central Asia](https://auca.kg) in Spring 2026.

Original data, questionnaires, and methodology available directly from [Central Asia Barometer](https://ca-barometer.org/en).

In particular, the [2022 Kyrgyzstan Survey in Excel format](https://ca-barometer.org/assets/files/projects/cab-survey-wave-12-excel-kyrgyzstan-kyrgyzstan-2022-autumn.xlsx) is the subject of the first exercise.
